# نظام إدارة فواتير الكهرباء

تطبيق عربي لإدارة مشتركي بيع الكهرباء، تسجيل قراءات العدادات وإصدار الفواتير الأسبوعية ومتابعة التسديد والتقارير حسب الفترة.

## التشغيل المحلي

يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm start
```

افتح `http://localhost:3000`. تُنشأ قاعدة SQLite تلقائياً في `data/electricity.db`، ويمكن تغيير موقعها عبر `DB_FILE`.

## الوظائف

- حسابات المشتركين مع رقم حساب فريد وتاريخ الاشتراك وقراءة عداد ابتدائية.
- القراءة السابقة في كل فاتورة تُسحب آلياً من القراءة الابتدائية عند أول فاتورة، ثم من آخر قراءة حالية مسجلة للحساب.
- يُدخل المستخدم القراءة الحالية فقط؛ يتحقق النظام من أنها لا تقل عن القراءة السابقة، ثم يحسب الاستهلاك والمبلغ تلقائياً.
- سعر الكيلوواط قابل للتحديث. تحفظ الفاتورة السعر المستخدم عند إنشائها ولا تتغير الفواتير السابقة.
- تسجيل التسديد وتاريخه، وقائمة الفواتير المستحقة.
- مؤشرات إجمالي السحب والمستحق والمحصّل والفواتير غير المسددة مع فلترة زمنية.
- حماية من تكرار فاتورة الحساب للفترة نفسها، ومن حذف حساب لديه فواتير.

## قاعدة البيانات

الجداول: `subscribers`, `invoices`, `settings`. ملفات قاعدة البيانات مستثناة من Git للحفاظ على خصوصية بيانات التشغيل. خذ نسخة احتياطية دورية من `data/electricity.db`.

## الميزات التشغيلية

- قراءة ابتدائية للعداد تحفظ مع حساب المشترك. القراءة السابقة لكل فاتورة تُحدد من آخر قراءة حالية محفوظة، أو من القراءة الابتدائية عند أول فاتورة.
- التحقق من عدم انخفاض القراءة الحالية، ومنع تكرار فاتورتين للحساب والفترة نفسيهما.
- التقارير تعرض إجمالي السحب والمستحق والمحصّل والمتبقي، والأرصدة غير المسددة مجمعة حسب المشترك؛ مع تصدير CSV.
- تسجيل تاريخ التسديد، وطباعة نسخة فاتورة.
- `/api/health` لفحص جاهزية الخدمة.
- شاشة إعداد تنشئ حساب المدير عند أول تشغيل؛ وبعدها يتطلب التطبيق تسجيل الدخول قبل الوصول للمشتركين والفواتير. كلمات المرور تُحفظ كتجزئة مشفّرة، وجلسة الدخول محمية بملف ارتباط `HttpOnly`.

## التشغيل باستخدام Docker / Coolify

من جذر المستودع:

```bash
docker compose up -d --build
```

تعمل الواجهة على المنفذ `3000` افتراضياً. قاعدة SQLite تحفظ في volume دائم اسمه `electricity_data`، لذلك تبقى البيانات عند إعادة بناء الحاوية أو تحديث التطبيق. في Coolify استخدم Docker Compose من هذا المستودع، واحتفظ بالـ volume `electricity_data` عند إعادة النشر. لا تحذف الـ volume عند التحديث.

لنسخة احتياطية من القاعدة بعد إيقاف التطبيق مؤقتاً:

```bash
docker compose cp electricity-billing:/app/data/electricity.db ./electricity-backup.db
```

بيانات `electricity-backup.db` خاصة بالمشتركين، ولا تُرفع إلى GitHub.
