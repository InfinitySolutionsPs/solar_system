# نظام إدارة فواتير الكهرباء

تطبيق عربي لإدارة مشتركي بيع الكهرباء، تسجيل قراءات العدادات وإصدار الفواتير الأسبوعية ومتابعة التسديد والتقارير حسب الفترة.

## التشغيل المحلي

يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm start
```

افتح `http://localhost:3000`. تُنشأ قاعدة SQLite تلقائياً في `data/electricity.db`، ويمكن تغيير موقعها عبر `DB_FILE`.

## الوظائف

- حسابات المشتركين مع رقم حساب فريد وتاريخ الاشتراك والحالة.
- فاتورة من قراءة سابقة وحالية؛ يحسب النظام الاستهلاك والمبلغ تلقائياً.
- سعر الكيلوواط قابل للتحديث. تحفظ الفاتورة السعر المستخدم عند إنشائها ولا تتغير الفواتير السابقة.
- تسجيل التسديد وتاريخه، وقائمة الفواتير المستحقة.
- مؤشرات إجمالي السحب والمستحق والمحصّل والفواتير غير المسددة مع فلترة زمنية.
- حماية من تكرار فاتورة الحساب للفترة نفسها، ومن حذف حساب لديه فواتير.

## قاعدة البيانات

الجداول: `subscribers`, `invoices`, `settings`. ملفات قاعدة البيانات مستثناة من Git للحفاظ على خصوصية بيانات التشغيل. خذ نسخة احتياطية دورية من `data/electricity.db`.
